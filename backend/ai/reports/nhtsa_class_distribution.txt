Mapping rules and rationale:
  - ENGINE AND ENGINE COOLING:EXHAUST SYSTEM:EMISSION CONTROL -> unmapped: Emissions-only subcomponents are outside the initial roadside model.
  - ENGINE AND ENGINE COOLING:COOLING SYSTEM -> cooling_system_fault: These subcomponents explicitly identify the engine cooling system.
  - POWER TRAIN:AUTOMATIC TRANSMISSION, POWER TRAIN:MANUAL TRANSMISSION, POWER TRAIN:TRANSMISSION, POWER TRAIN:CLUTCH ASSEMBLY -> transmission_fault: These power-train subcomponents explicitly identify a transmission or clutch assembly.
  - SERVICE BRAKES, PARKING BRAKE -> brake_system_fault: NHTSA brake, hydraulic, air, electric, ABS, and parking-brake components map directly to the project brake class.
  - ELECTRICAL SYSTEM -> electrical_system_fault: The NHTSA component explicitly identifies the vehicle electrical system.
  - ENGINE -> engine_system_fault: Broad ENGINE and legacy ENGINE AND ENGINE COOLING components are retained as engine faults unless a preceding cooling or emissions rule applies.
  - FUEL SYSTEM, FUEL/PROPULSION SYSTEM -> fuel_system_fault: These components identify fuel storage, delivery, injection, or propulsion-system complaints.
  - TIRES, WHEELS -> wheel_tire_fault: Tyre and wheel components map directly to the project wheel/tyre class.
  - STEERING -> steering_system_fault: The NHTSA component explicitly identifies the steering system.
  - POWER TRAIN -> drivetrain_fault: Non-transmission power-train components map to the project drivetrain class.
